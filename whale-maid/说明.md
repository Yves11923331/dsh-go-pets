# 嫌弃の鲸鱼女仆

模型：gpt-image-2.6-flare（GPT 通道）
画布：**200 × 200**，非像素平滑绘制（pixelArt: false）
id：`whale-maid`

## 内容

21 个动画，全部 GIF 合成：

- 状态（12）：待机、思考、干活、分身、报错、完成、提醒、清理、搬运、睡觉、醒来、游走
- 反应（5）：被戳、点赞、挠痒、嫌弃、被拎
- 待机小剧场（4）：打哈欠、赌气、发呆、微笑

符号（代码符号、汗滴、怒气、Zzz、星星、音符）由 2.6 直接画进表情图，本地只做呼吸/抖动/眨眼。

## 用

导入：设置 → 宠物 → 导入 → 选 `whale-maid.zip`
（同 id 覆盖旧包）

`gifs/` 里是各状态 GIF，可直接点开看。

## 备注

- 200 画布下人物内容约 166×167，符号比 144 版清楚很多
- 各状态之间是硬切，宠物包本身不支持跨状态过渡
